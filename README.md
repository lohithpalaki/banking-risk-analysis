# banking-risk-analysis
An interactive Banking Risk Analysis Dashboard built using **Python**, **Streamlit**, **Pandas**, and **Plotly** to analyze customer demographics, banking transactions, loan portfolios, and credit card performance. The application provides insightful visualizations and KPIs to support data-driven decision making.

---

## 📌 Features

- 🔐 Secure Login Authentication
- 📊 Customer Demographics Dashboard
- 💳 Account & Loan Analysis
- 💸 Transaction Analysis
- 💳 Credit Card Performance Dashboard
- 📈 Interactive KPIs
- 📉 Dynamic Charts using Plotly
- 📱 Responsive Streamlit Interface

## 📊 Dashboard Modules

### 1️⃣ Customer Demographics

- Total Customers
- Gender Distribution
- Age Group Analysis
- Customer Distribution by City

---

### 2️⃣ Accounts & Loan Analysis

- Total Account Balance
- Total Loan Amount
- Average Interest Rate
- Loan Count by Year
- Loan Term Distribution

---

### 3️⃣ Transaction Analysis

- Monthly Transaction Trends
- Transaction Type Distribution
- Total Transaction Amount
- Average Transaction Value

---

### 4️⃣ Credit Card Analysis

- Credit Card Balance
- Credit Limit Analysis
- Monthly Minimum Payment Due
- Reward Points Analysis
